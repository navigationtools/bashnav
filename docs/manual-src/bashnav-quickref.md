# BASHNAV quick reference
**Version {{VERSION}}** — one icon, all the tools behind it.

## The six

| | |
|---|---|
| `celnav` | celestial navigation: sight reduction and the fix |
| `colregs` | the rules of the road, lights, collision avoidance |
| `tides` | tide prediction, 8,334 stations |
| `deck-log` | the boat's records: deck, engine, provisions |
| `weather` | read your own barometer |
| `drill` | a study machine — browser build only |

## At a prompt

`bashnav` prints the list; pick a number. It looks for each tool next to
itself, then in `bin/` beside it, then `~/Documents`, `~/bin`, the current
directory, and finally your `PATH`.

## In a browser

1. Open a tool.
2. **Share → Add to Home Screen.**
3. Repeat per tool — each is its own page, so each gets its own icon.

No installer, nothing to update by hand: a tool reloads itself when its page
changes.

## Prove offline at the dock

1. Open every screen of the tool, online, once.
2. Turn the network off.
3. **Close it completely and relaunch from the icon.**
4. Open the same screens again.

A tool that was only ever opened online has shown you nothing about offline.

## The three modes

**DAY · DARK · NIGHT**, shared across the whole suite, night by default, and
night to day takes a deliberate hold. A bright panel costs a dark-adapted eye
about twenty minutes.

## The standing caution

Training aids and working tools, **not a substitute for judgement**. Where any
of these and the published rules, almanac or chart differ, the published
source is right and this is wrong.
